## 实现约定

- 接收到的附件默认归档到**接收者的 LinkOS Downloads**。聊天设置允许选择可写目录；目录被删除、权限被撤销或移入废纸篓时回退到私有 Downloads。下载到本机的真实磁盘位置仍由浏览器控制。
- 发送端提交资源 ID，服务端校验权限并生成文件名、大小、内容哈希快照。接收记录独立于发送源文件，复用现有 CAS 字节；发送者删除源条目不会删除对方已接收的条目。
- 消息和自动接收记录在同一状态事务中保存。按作者、频道、clientMsgId 去重；接收记录按用户和消息去重。持久化失败不发布部分结果。读取已有接收记录不再次写入整个状态。
- 个人系统目录不可重命名、移动或删除，内容按权限正常管理。其他成员不能访问个人目录，管理员也不能绕过私聊成员检查。广播只传失效通知，私有内容通过鉴权 API 获取。
- 批量操作最多 100 个根项目、累计 2,000 个条目，校验整个子树及目标目录，拒绝循环移动。复制不继承源 ACL；同名条目自动改名。
- 附件上传复用已有分片、哈希、重试与续传逻辑。每条消息最多 16 个附件/内容块，代码片段最多 64 KiB；HTML/SVG 不作为可执行预览嵌入。快速查看限制 5 MiB，并释放请求与对象 URL。
- 草稿按 Gateway、工作区、用户、频道和线程隔离；失败重试保留消息 ID。Dock 顺序按用户与工作区保存。动画支持 `prefers-reduced-motion`，触屏不启用悬停放大。

## 验证结果与复现

已通过：

1. TypeScript：`node apps/web/node_modules/typescript/bin/tsc --noEmit -p apps/web/tsconfig.json`。
2. 前端单测：在 `apps/web` 下执行 `node --import tsx --test "src/**/*.test.ts"`，126/126 通过。
3. Go：`go test ./services/gateway/... ./services/runner/...`，全部通过。新增契约覆盖权限、子树原子操作、循环、废纸篓恢复、附件快照、防重复、私聊过滤、自定义目录回退、持久化失败回滚/重载、最新消息分页。
4. 生产构建：在 `apps/web` 下执行 `node node_modules/vite/bin/vite.js build`，通过。
5. HTTP：[`scripts/verify-desktop-iteration.mjs`](../../scripts/verify-desktop-iteration.mjs) 使用三个真实会话，验证分片上传/CORS、私聊成员、自动进入 Downloads、下载字节一致、重试去重、自定义目录、复制与废纸篓恢复。需显式设置 `LINKOS_ACCEPTANCE_GATEWAY` 指向独立验收服务；脚本创建合成数据，要求服务允许普通成员登录。
6. 浏览器人工验收：Downloads 创建目录、Enter 重命名、删除到废纸篓、恢复原目录、Dock 最小化/还原、代码消息展示；390px 聊天与输入区可用、页面宽度没有溢出，会话列表可返回。

已有 Playwright 用例已同步新的输入标签和 Finder 删除/键盘语义，`--list` 可加载全部 86 个用例；**本轮未执行完整 Playwright 桌面/手机矩阵**。浏览器原生附件选择器的自动化未能完成，本轮文件传输以真实 HTTP 链路、上传器单测和 Go 契约验收为依据。
