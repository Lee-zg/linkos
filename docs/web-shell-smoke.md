# Web Shell 冒烟验证

用途：在没有完整 E2E 测试运行器时，复现 LinkOS 桌面 OS 的关键交互。该清单不替代 Playwright/契约测试，自动化脚本将在 S0-06 后续任务中补齐。

## 启动

在仓库根目录启动 Gateway 和 Web：

```powershell
go run ./services/gateway
pnpm --filter @linkos/web dev --host 127.0.0.1 --port 5173
```

打开 `http://127.0.0.1:5173/`。如果 pnpm 在非交互终端触发 `ERR_PNPM_ABORTED_REMOVE_MODULES_DIR_NO_TTY`，使用仓库已安装的 Node/Vite 运行时启动开发服务器。

## 桌面端（1440x900）

- 首屏显示黑色宇宙壁纸、7 个桌面应用图标和底部居中 Dock。
- 启动 Toast 显示“系统就绪”和工作区连接信息，并在短时间后消失。
- 单击桌面图标只改变选中状态；双击“系统状态”打开窗口。
- 窗口标题栏高度稳定，关闭/最小化/最大化按钮有可访问名称。
- 点击窗口内容后窗口置顶；拖动标题栏和右下角手柄不会导致内容跳动。
- 最小化窗口后，Dock 运行指示仍存在；再次点击 Dock 恢复并置顶，不自动最小化。
- 关闭窗口后 Dock 运行指示消失；再次点击 Dock 可以重新打开。
- 点击“聊天”，输入消息并发送；消息出现在列表，Gateway 收到 `POST /api/v1/messages`。
- 点击“任务”运行示例任务，状态依次经过 `preparing`、`running`、`succeeded`。

## 移动端（390x844）

- 刷新页面后桌面图标仍可见，单击图标直接打开应用。
- 窗口变为全屏 Sheet，底部 Dock 保留且不遮挡消息输入框或主要内容。
- 关闭、最小化和返回桌面后，应用状态与 Dock 运行指示一致。
- 聊天断开 WebSocket 时发送按钮禁用，连接恢复后重新可用。

## 记录格式

每次验证记录日期、浏览器版本、视口、通过/失败项、控制台错误和 Gateway 日志。失败项关联任务 ID，不把“页面能打开”作为后端功能完成证明。
