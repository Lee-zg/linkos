# ADR-003：Runner 隔离执行边界

- 状态：技术验证准备中
- 日期：2026-08-31
- 关联任务：P0-03、S0-05

## 背景

LinkOS 的 Runner 会执行成员提交的编译和运行任务。任务命令、环境变量、输入文件和输出日志都属于不可信输入；局域网并不等于可信网络。当前 Runner 只提供健康检查、注册和拒绝执行的 `/jobs` stub，所有任务都返回 `501 sandbox_not_configured`。

## 决策

在隔离适配器通过安全评审前，Runner 必须保持“默认拒绝执行”状态。Gateway 的任务状态模拟不能被视为 Runner 执行成功，也不能绕过 Runner 的策略检查。

候选隔离适配器需要满足以下最小边界：

- 每个 Job 使用独立临时目录和非 root 用户。
- 基础文件系统只读；只挂载明确声明的输入资源和输出目录。
- 默认无网络；allowlist 只能由服务端策略批准，不能由客户端命令自行开启。
- 强制 CPU、内存、磁盘和最长运行时间配额。
- 任务结束后清理进程、子进程、挂载、临时文件、网络命名空间和短期凭据。
- 命令行、环境变量和日志经过敏感信息脱敏；不把宿主路径或内部堆栈返回给普通成员。
- Runner 注册使用短期令牌或 mTLS；管理员可以吊销、暂停和排空节点。

实现路线在 Phase 0 通过 PoC 对比：Linux 优先验证 rootless container；无法部署容器的环境再评估 WASI/平台等效隔离。Windows 与 macOS 的隔离能力必须单独记录，不假设 Linux 机制可直接复用。

## 负面测试清单

以下测试必须在执行适配器启用前通过：

| 类别 | 负面场景 | 预期结果 |
| --- | --- | --- |
| 文件 | 访问宿主根目录、Gateway 数据库、其他 Job 目录 | 访问被拒绝；无越权文件内容进入日志 |
| 路径 | `../`、绝对路径、符号链接逃逸、设备文件 | 请求拒绝或路径解析到 Job 沙箱内 |
| 进程 | fork bomb、后台守护进程、子进程不退出 | 超时/进程组终止；Runner 可继续接收后续任务 |
| 资源 | 超出 CPU、内存、磁盘配额；无限输出日志 | Job 失败并记录策略错误；队列和日志内存有界 |
| 网络 | 默认访问公网、局域网其他主机、DNS 重绑定 | 无网络；allowlist 之外连接失败并审计 |
| 凭据 | 读取 Runner 环境变量、配置文件、挂载 token | 不可见；命令和日志中的敏感值被脱敏 |
| 协议 | 伪造 Runner ID、重复注册、过期注册令牌 | 注册拒绝或旧会话吊销；不接收任务 |
| 取消 | 优雅取消后继续写文件或启动子进程 | 强制终止并清理；最终状态为 `canceled` |
| 容器 | 提权、挂载宿主路径、capability 绕过、内核接口访问 | 创建任务失败；产生安全审计事件 |

## Phase 0 退出条件

- 至少一个隔离适配器在 Linux 上跑通 Go/Node/Python 示例任务。
- 上表每个类别至少有一个自动化负面测试，且失败日志不泄露敏感数据。
- 任务状态、日志和产物能关联 Job ID、Runner ID、提交版本和审计记录。
- 资源配额和超时在 100 个并发 Job 的压测中不会造成无界进程或内存增长。
- 安全负责人批准后，才允许把 Runner `/jobs` 从 `501` 切换到真实执行路径。
